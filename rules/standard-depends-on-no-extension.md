# The standard depends on no extension

**Rule:** The standard may list an extension, and never read, run, import or copy what one holds.

**Grade:** convention.

## Why

- A standard that read its extensions would break whenever one changed.
- A link is a reference, not a dependency, so the standard can still list its extensions.
- The map that points both ways therefore lives on the front page of this repository.
